# 🫧 싱글 버블파이터

**30초 동안 몰려오는 적을 최대한 많이 처치하는 2D 싱글 플레이 미니게임**

마우스로 적을 조준하고 WASD로 이동하면서 제한 시간 안에 높은 점수를 기록하는 게임입니다.

## 🎮 게임 목표

* 제한 시간: **30초**
* 적 1마리 처치: **100점**
* 적에게 공격받으면 HP 감소
* HP가 0이 되면 게임 오버
* 30초가 지나면 게임 종료
* 게임 종료 후 다시 시작 가능

## 🕹️ 조작 방법

| 조작                 | 기능        |
| ------------------ | --------- |
| `W A S D`          | 플레이어 이동   |
| `방향키`              | 플레이어 이동   |
| `마우스`              | 조준        |
| `마우스 왼쪽 버튼`        | 발사        |
| `마우스 왼쪽 버튼 길게 누르기` | 자동 연사     |
| `Space`            | 발사        |
| `ESC`              | 일시정지 / 재개 |

## 🎯 자동 조준

조준점 주변에 적이 있을 경우 **약한 자동 조준 보정**이 적용됩니다.

플레이어의 조작을 대신하는 방식이 아니라, 조준점 근처에 있는 적을 찾아 탄환의 방향을 일부 보정하는 방식으로 구현했습니다.

### 동작 방식

1. 조준점 주변의 적을 확인합니다.
2. 조준점과 가장 가까운 적을 선택합니다.
3. 해당 적의 방향으로 탄환의 진행 방향을 일부 보정합니다.
4. 자동 조준이 적용될 경우 조준점이 노란색으로 표시됩니다.

따라서 직접 조준하는 재미는 유지하면서 조금 더 편하게 적을 맞힐 수 있도록 설계했습니다.

## 👾 적 종류

### 🔴 추적형

플레이어의 위치를 직접 따라오는 기본적인 적입니다.

### 🟡 지그재그형

플레이어를 향해 이동하면서 좌우로 흔들리며 접근합니다.

### 🟣 돌진형

평소에는 천천히 접근하다가 일정 거리 안으로 들어오면 빠르게 돌진합니다.

돌진하기 전에 시각적인 경고 효과가 나타납니다.

## ❤️ 체력 시스템

플레이어의 최대 HP는 **100**입니다.

적이 가까이 접근하면 공격하며, 공격을 받은 뒤에는 짧은 시간 동안 피해를 받지 않는 무적 시간이 적용됩니다.

HP가 0이 되면 게임이 종료됩니다.

## ⏸️ 일시정지

`ESC`를 누르면 게임을 일시정지할 수 있습니다.

일시정지 중에는 게임 시간이 진행되지 않으며, `ESC` 또는 **계속하기** 버튼으로 게임을 재개할 수 있습니다.

브라우저 창의 포커스를 잃은 경우에도 게임을 자동으로 일시정지하도록 구현했습니다.

## 🏆 기록 저장

브라우저의 `localStorage`를 이용해 플레이 기록을 저장합니다.

저장되는 정보:

* 최고 점수
* 최고 처치 수
* 효과음 설정

저장 데이터가 없거나 잘못된 형식으로 저장되어 있어도 게임이 중단되지 않고 기본값으로 복구하도록 처리했습니다.

## 🔊 효과음

간단한 Web Audio API 기반 효과음을 사용합니다.

* 발사 효과음
* 적 처치 효과음

하단의 **효과음 끄기** 옵션으로 효과음을 끌 수 있으며 설정은 브라우저에 저장됩니다.

## 🛠️ 사용 기술

* HTML5
* CSS3
* JavaScript
* HTML5 Canvas
* Web Audio API
* localStorage

별도의 게임 엔진 없이 **JavaScript와 Canvas API를 이용해 게임의 핵심 로직을 직접 구현**했습니다.

## 💡 구현하면서 고려한 점

### 짧은 시간 안에 게임의 흐름이 완성되도록 구성

게임 시작 → 이동 및 사격 → 적 처치 → 점수 획득 → 성공/실패 → 다시 시작까지 하나의 라운드 안에서 경험할 수 있도록 구성했습니다.

### 직접 조준하는 재미와 편의성의 균형

자동 조준을 강하게 적용하면 플레이어가 직접 조준할 필요가 없어지기 때문에, 조준점 주변의 적에게만 제한적으로 보정이 적용되도록 했습니다.

### 게임 상태와 기록 분리

현재 플레이의 점수, HP, 시간 등은 새 게임을 시작할 때 초기화하고, 최고 점수와 최고 처치 수는 `localStorage`에 별도로 저장하도록 구성했습니다.

### 오류가 발생해도 게임이 중단되지 않도록 처리

저장된 데이터가 없거나 손상된 경우 기본값을 사용하도록 처리하여 게임 실행에 영향을 주지 않도록 했습니다.
